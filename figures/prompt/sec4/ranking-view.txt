USER CONTEXT PROMPT

Use case: scientific-educational
Asset type: full-width mechanism diagram for a Chinese undergraduate textbook

Source context:
Authoritative user power data is distributed across three PostgreSQL shards. Each shard generates a local Top100. A background leaderboard aggregation service collects these lists, merges and sorts them, and writes a derived global leaderboard into Redis. User requests read only Redis and receive the full-server Top100.

Teaching goal:
Show that cross-shard fan-out and merge happen in the background update path, while the user query path reads only the materialized Redis leaderboard.

Beginner misconception to prevent:
Redis is not the source of authoritative user power data and does not query PostgreSQL shards live for every user request.
