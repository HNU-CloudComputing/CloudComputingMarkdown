Source context from the textbook:
The game server sends application-level state updates A, B, and C in order. When A is lost, TCP receives later bytes for B and C but cannot deliver them to the application until the missing earlier bytes are retransmitted. UDP treats A, B, and C as independent datagrams, so B and C can still reach the application. The application then decides by message semantics whether a new state may cover an old state or a key event needs confirmation and retransmission.

Teaching goal:
