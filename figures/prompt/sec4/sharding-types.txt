## 教学任务

**顶部**：一组用户图标，代表"所有用户请求"。

**三列并列**（从左到右）：

1. **连接分片**（左列）
   - 标题：连接分片
   - 分片键标注：SessionID / 入口区域
   - 画 3 个网关实例（Gateway A, Gateway B, Gateway C）

2. **计算分片**（中列）
   - 标题：计算分片
   - 分片键标注：ModuleID / RoomID
   - 画 3 个逻辑服实例（逻辑服 A, 逻辑服 B, 逻辑服 C）
   - 箭头从网关到逻辑服，标注"按模块/房间分配"

3. **存储分片**（右列）
   - 标题：存储分片
   - 分片键标注：UserID / OrgID
   - 画 3 个数据库实例（DB Shard 1, DB Shard 2, DB Shard 3）
   - 箭头从逻辑服到数据库，标注"按用户 ID 路由"
   - 每个数据库内部标注"用户数据"

**底部**：一行总结文字——"三类分片共享通用机制：分片键选择 → 映射策略 → 路由查找 → 负载监测 → 动态调整"
