Use case: scientific-educational
Asset type: concept figure for a Chinese undergraduate cloud computing textbook
Primary request: Draw a vertical flow architecture diagram showing how a cross-node transaction uses a single coordinator to generate a unique result, which is then executed by multiple application servers.

Source context from the textbook:
This figure illustrates the "single-source-of-truth" architecture for cross-server transactions. When a transaction involves users on different servers, no single application server can decide the result independently. Instead, a dedicated coordinator server maintains global state, validates the request, generates a unique result, and distributes it to the relevant application servers for local execution.

Teaching goal:
Show that the coordinator is the ONLY node that can generate the official result, while application servers only forward requests and update their local users' states.

Beginner misconception to prevent:
Students may think each application server can decide the result based on its local data. The figure must make clear that all request logic flows to the coordinator, and only execution logic flows back to the application servers.
