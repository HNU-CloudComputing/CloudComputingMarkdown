Source context from the textbook:
The text explains that a container sends packets from eth0 through veth and docker0 bridge into the host network stack. Routing can forward the packet to the physical NIC, but the container's private IP address is not reachable from the external network. SNAT, usually implemented by iptables MASQUERADE or nftables rules, rewrites the outgoing source address to the host external address and records the mapping in conntrack. The return packet is then restored and sent back to the original container.

Teaching goal:
Show the outbound SNAT path and the return conntrack restore path as one bidirectional mechanism.
