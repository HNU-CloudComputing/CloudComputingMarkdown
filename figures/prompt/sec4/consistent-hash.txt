# 一致性哈希环示意图

## 教学任务
展示一致性哈希的核心机制：节点和数据键映射到同一个哈希环；查询时沿顺时针找到最近的虚拟节点；新增节点只影响相邻局部区间。

## 图片内容描述

整体布局：中心是一个蓝色圆环（一致性哈希环），环上均匀分布着若干小圆点（虚拟节点）。环的外围放置数据库节点，环的内侧/外侧放置数据键示例和说明框。

**中心圆环**：
- 圆环上均匀分布若干小圆点，分为四种颜色/样式，分别代表属于节点A、B、C、D的虚拟节点。
- 环上标注若干数据键位置：P101、P238、P779、P904、P301、P512 等（用带颜色的小圆点或标签标注在环上）。

**外围节点**（放在环外，用箭头或虚线指向环上的虚拟节点）：
- 左上方：**数据库节点 A**（蓝色圆柱图标），旁边用虚线框标注"虚拟节点（属于节点 A）"。
- 右上方：**数据库节点 B**（蓝色圆柱图标）。
- 左侧中部：**数据库节点 C**（蓝色圆柱图标），旁边用虚线框标注"虚拟节点（属于节点 C）"。
- 底部中央偏右：**新增节点 D**（橙色圆柱图标），标注"新增节点 D"。

**三个编号教学标签**（放在环周围，用圆角矩形+编号）：

1. **① 节点映射到环**（左上角）
   - 箭头从"数据库节点 A"指向环上属于A的虚拟节点群。
   - 旁边虚线框标注"虚拟节点（属于节点 A）"。

2. **② 数据键映射到环**（右上角）
   - 一个数据键（例如 P101）标注在环上。
   - 从数据键引出一条虚线箭头，**顺时针方向**指向最近的归属节点（数据库节点 B）。
   - 箭头终点标注"归属节点"。
   - 旁边虚线框标注"用户 ID"（或"数据键"），表示这是被映射到环上的数据对象。

3. **③ 顺时针找到最近节点**（环的下方偏左，或底部中央）
   - 明确展示一条**顺时针查询路径**：从某个数据键位置（如 P301 或 P512）出发，沿环的顺时针方向画一条弧线箭头，指向遇到的第一个虚拟节点，再指向该虚拟节点所属的物理节点。
   - 箭头样式：虚线或带方向的弧线，清晰表示"顺时针查找"。
   - 目的：让读者一眼看懂"如何确定归属"。

新增节点 D 插入环后，仍用橙色高亮显示 D 相邻的局部区间，并用箭头标注“迁到 D”；但不再单独放置编号 ④ 和“新节点只接管一小段”标签框。

**右侧验证框**（竖向排列，放在图的最右侧）：
- 标题："新增节点不影响全环"
- 三个勾选/锁图标条目：
  - ✅ "A 到 B 区间保持不变"
  - ✅ "B 到 C 区间保持不变"
  - 🔒 "仅局部迁移区间受影响"

**右下角图例**：
- 小圆点颜色对应四种归属：
  - 🔵 属于节点 A 的虚拟节点
  - 🟢 属于节点 B 的虚拟节点
  - ⚪ 属于节点 C 的虚拟节点
  - 🟠 属于新增节点 D 的虚拟节点
